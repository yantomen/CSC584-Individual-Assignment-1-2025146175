# Personal Profile Web Application

## Project Description

This project is developed for CSC584
Individual Assignment 1.

The application allows students to submit
their personal information using an HTML form.
The Java Servlet processes the information
and displays it on a JSP page.

## Technologies Used

- HTML
- CSS
- Java
- Java Servlet
- JSP
- NetBeans 8.2
- GlassFish Server

## Features

1. Personal information form.
2. HTTP POST submission.
3. Java Servlet processing.
4. JSP profile display.
5. CSS styling.

## How to Run

1. Open the project in NetBeans 8.2.
2. Configure GlassFish Server.
3. Right-click the project.
4. Select Clean and Build.
5. Select Run.
6. Open the application in your browser.
